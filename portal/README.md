# TA Portal

Private technical-analysis portal: charts for 1D/5D/1M/3M/6M/1Y/5Y,
auto-drawn indicators, support/resistance, signals, multi-ticker comparison,
and owner theories as plug-in modules. Personal and team use only.

Static HTML + ES modules, no build step. Charts: Lightweight Charts 5.0.9
(jsDelivr, SRI-pinned). Data: Yahoo Finance through the Worker in `../worker`.

## Run tests

```bash
node --test portal/tests/
```

`tests/index.js` imports every `*.test.js` file (Node 22 resolves a directory
argument to its `index.js`). Fixtures are synthetic, generated by
`tests/fixtures/generate.js`, so no Yahoo data is committed.

## URL state

`?t=AAPL&tf=1Y&cmp=SPY,QQQ&ind=sma,volume,rsi,macd&lv=0`

| Param | Meaning |
|---|---|
| `t` | Primary ticker |
| `tf` | `1D` `5D` `1M` `3M` `6M` `1Y` `5Y` |
| `cmp` | Up to 5 comparison tickers (switches the price pane to % return) |
| `ind` | Active modules, by id |
| `lv=0` | Hide support/resistance lines |

Theme and colorblind palette are per-viewer (localStorage).

## Implementation notes

| Topic | Choice |
|---|---|
| Warm-up | Each timeframe fetches a longer range (`timeframes.js`), indicators compute on the full set, then output is trimmed to the visible window |
| Volume spike | Volume > 2 × mean of the **previous** 20 bars (current bar excluded) |
| Bollinger squeeze | Band width at its lowest of the trailing 126 bars; fires on the first bar of a squeeze |
| Band breaks, crosses | Fire on the first bar outside / the crossing bar only |
| Divergence | Last two confirmed 5/5 pivots of the same type; signal placed at the confirmation bar |
| S/R levels | Computed on the visible window, cluster tolerance 0.5 × ATR14 of the full series |
| Compare volatility | stdev(per-bar returns) × √(bars per year): 252 daily, 52 weekly, 78×252 for 5m, etc. |
| Chart markers | SMA20 crosses appear only in the summary panel (too frequent for markers) |
| Yahoo quirks | Live "today" weekly bar folded into the current week; flat zero-volume 16:00 closing print dropped |

## Deploy (Cloudflare)

1. **Pages project** from this repo: build command none, output directory `portal`.
   Attach a custom hostname (the portal host).
2. **Worker**: `cd worker && npx wrangler deploy --route "<portal-host>/api/*"`.
   Set secrets: `wrangler secret put ACCESS_TEAM_DOMAIN`, `wrangler secret put ACCESS_AUD`.
   `workers_dev = false` keeps the un-gated workers.dev URL off.
3. **Access application** (Zero Trust → Access → Applications → Self-hosted):
   hostname = portal host (covers `/api/*` too). Policy: Include → Emails (owner's
   allow-list). Session duration 24 h. Copy its AUD tag into `ACCESS_AUD`.
4. If the API ever moves to another origin: set `<meta name="ta-api-base">` in
   `index.html`, `ALLOWED_ORIGIN` on the Worker, and add the origin to
   `connect-src` in `_headers`.

The Worker verifies the `Cf-Access-Jwt-Assertion` JWT (signature, `aud`, `iss`,
`exp`) and returns 403 without it. Never commit emails, tokens or account IDs.
